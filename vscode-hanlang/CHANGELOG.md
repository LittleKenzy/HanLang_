# Changelog

## [0.1.0] — 2026-10-25

### Added
- Syntax highlighting for all HanLang constructs
- TextMate grammar covering keywords, builtins, strings, interpolation, numbers, operators
- 25+ code snippets for common HanLang patterns
- Autocomplete for keywords, built-in functions, and stdlib module members
- Context-aware module member suggestions (math., text., list., etc.)
- Signature help for built-in and module functions
- Hover information for keywords and built-in functions
- User-defined symbol suggestions from current document
- Commands: Run File, Check File, Show Output, Open Docs
- Keyboard shortcuts (Ctrl+Shift+R for run, Ctrl+Shift+C for check)
- Right-click context menu integration
- Editor title bar Run button for .han files
- Status bar HanLang indicator with quick run
- Auto-detect interpreter (han.py) in workspace
- Configurable interpreter path, extra args, terminal mode
- Language configuration for brackets, quotes, comments, indentation
- Custom .han file icon for Explorer and editor tabs
- HanLang icon theme
- Extension marketplace icon
